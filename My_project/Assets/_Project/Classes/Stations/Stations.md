# Станции: минимальный набросок

- **Назначение**: статичные объекты внутри StarSys, тикаются ИИ по ходу. Позиция фиксирована в системе (Vector3 локально).
- **Состав минимума**: карго‑модуль (ёмкость, заполнение), док‑модуль (слоты стыковки, занятость). Остальные модули подключаем позже.
- **Данные станции**: `UID`, `OwnerFrac`, `Position`, `Modules[]`, базовое состояние (целостность/энергия при появлении). Модуль = тип + параметры + текущее состояние.
- **Инвентарь**: единое карго станции (просто, быстро) или раздельно по модулям (дороже, но гибко). Для MVP — общий склад, модули проверяют доступное место.
- **Док**: слоты с якорями/очередью, умеет принять/освободить корабль, отдаёт позицию стыковки.
- **Тик логики**: активная система — по FixedUpdate; оффлайн — батч за ход. Модули сами считают потребление/прогресс.
- **Визуал**: отдельный слой рендера на системной карте (аналог `SystemMapShipRenderer`), префаб по типу станции из `PrefabCatalog`, ставим в `Position`. Добавить поддержку `ESelectedObjectType.Station`.
- **Генерация/постройка**: сейчас — ручное добавление в StarSys генератором. Позже — процесс строительства/апгрейда станции игроком.
- **Расширяемость модулей**: Cargo, Dock, ProductionLine, Hab, Research, Repair, Trade, Equipment и т.п.; каждый модуль хранит свой конфиг (скорости/слоты/баффы) и состояние.
