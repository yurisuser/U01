# Архитектура экипировки (черновик)

Назначение: правила сборки экипировки корабля и хранения её набора.

## Контракт
- `EquipService.EquipShip(in Ship ship, int qualityEquip)` возвращает `EquipSet`.
- Корабль не изменяется внутри сервиса.

## Параметр qualityEquip
- Отвечает за качество/уровень экипировки.
- Используется так же для выбора модулей из БД по `tech_level`.
- Диапазон: 0..100.
        - 0 — треш с синей изолентой.
        - 100 — броня из душ инопланетян.

## Источник данных
- Таблицы: `weapons`, `engines`, `scanners`, `shields`.
- У оборудования есть `tech_level` для фильтрации.

## EquipSet
- Хранит набор модулей для установки.
- Детали полей определим позже.

## Ограничения корабля
- Оборудование должно помещаться по общим лимитам: `power` и `cpu`.
- Дополнительные ограничения слотов применяются только для части оборудования.
- Пока слоты только для: пушки, щиты, двигатели.
- `power` и `cpu` — встроенные характеристики корабля.
 - У оборудования есть `power_use` и `cpu_use` (расход при установке).

## Примечания
- В «детских» регионах качество ниже, в «хай‑енд» — выше.
- Логику подбора фиксируем после определения правил баланса.
