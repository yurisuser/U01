# Структура симуляции

## Цель
Простая и расширяемая схема: один каркас, две симметричные ветки (глобальная и локальная), чёткий порядок стадий.

## Карта папок
```
Simulation/
  Core/
    SimulationRootController.cs   // оркестратор: решает, когда тикать Global/Local, держит общий счётчик ходов/времени
    SimulationClock.cs            // единый счётчик ходов/дней и dt для Local
    ISimulationPipeline.cs        // контракт пайплайна (RunStep, порядок стадий)
    ISimulationStage.cs           // контракт стадии (Run(context))
    SimulationStepContext.cs      // базовый контекст: tick, ссылки на GameState, буферы логов/событий

  Global/
    GlobalSimulationPipeline.cs   // конвейер стадий за один глобальный ход (1 ход = 1 день)
    GlobalSimulationContext.cs    // контекст глобального шага: текущий день, ссылки на мир, временные буферы
    Stages/
      01_Input.cs                 // вход игрока на галактике, таймеры кампании, скриптовые события
      02_Perception.cs            // оценка галактики: кто где, фронты, контроль систем
      03_Ai.cs                    // стратегические решения фракций/флотов
      04_Movement.cs              // движение флотов по маршрутам между системами
      05_Interaction.cs           // торговля/снабжение/дипломатия на стратегическом уровне
      06_Combat.cs                // результаты крупных сражений флот–флот (без тактики)
      07_Events.cs                // события дня: падение системы, войны, экономика
      08_Snapshot.cs              // сбор среза для GalaxyMap
    Snapshot/
      GlobalRenderSnapshot.cs     // read-only данные для отрисовки галактики
      GlobalSnapshotBuilder.cs    // строит снапшот из GameState

  Local/
    LocalSimulationPipeline.cs    // конвейер локальных стадий для активной системы (дергается из FixedUpdate)
    LocalSimulationContext.cs     // контекст локального шага: dt, активная система, локальные буферы
    Stages/
      01_Input.cs                 // команды игрока в системе, локальные триггеры/приказы
      02_Perception.cs            // видимые цели/угрозы/точки интереса
      03_Ai.cs                    // тактические решения юнитов
      04_Movement.cs              // движение кораблей/снарядов, сабшаги
      05_Interaction.cs           // стыковка, погрузка, ремонт, сервисы станций
      06_Combat.cs                // тактический бой: выстрелы, урон, уничтожение, обломки
      07_Events.cs                // события: убийства, криты, завершения задач, сообщения игроку
      08_Snapshot.cs              // срез для SystemMap
    Snapshot/
      LocalRenderSnapshot.cs      // read-only данные для отрисовки текущей системы
      LocalSnapshotBuilder.cs     // собирает снапшот из локального состояния
```

## Принципы
- GameState живёт в Core (не в Simulation); Simulation читает/меняет его через сервис.
- Порядок стадий фиксируем явным списком, номера в именах — для читаемости.
- Стадии — классы (ISimulationStage/StageBase), коллекции стадий без боксинга.
- Контекст передаётся в каждую стадию; стадии не тянут singletons напрямую.
- Snapshots — чистые DTO только для чтения; рендеры читают только их.
- Новая стадия: файл в `Stages/NN_Name.cs` + регистрация в пайплайне.
