# Constellations

Назначение: генерация созвездий и гиперпереходов внутри галактики.

## Основной поток
- `ConstellationCreator.Generate`:
  - строит матрицу расстояний;
  - создаёт делоне-граф по XY;
  - отрезает периферию и возвращает минимум связи;
  - сидит созвездия и расширяет их по графу;
  - удаляет межсозвездные связи и оставляет лучшие мосты;
  - записывает ссылки в `StarSys.links`.

## Предпосылки
- Индекс 0 считается центральной системой и исключается из созвездий.
- Генератор использует `static`‑состояние и не реентерабелен.

## Риски/тонкие места
- Сортировка расстояний зависит от корректного компаратора.
- При изменении правил созвездий нужно пересчитывать `links`.

## Неиспользуемые типы
- `ConstellationGroup`, `ConstellationFragment`, `ConstellationLinkEdge` — сейчас не используются.
