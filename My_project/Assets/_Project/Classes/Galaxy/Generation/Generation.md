### Решения по созвездиям (уточнено)
- Внутри группы у каждой звезды должно быть от 1 до 4 гиперпереходов (степень узла).
- Между соседними созвездиями — один гиперпереход.
- Все связи одинаковые: межгрупповые ничем не отличаются от внутригрупповых, хранение только в `StarSys`.
- Ограничение длины линка подбираем в диапазоне 7–20 (точное значение выбрать при реализации).
- Разбиение созвездий вести по `oldX/oldY`: первое созвездие строить рядом с (0,0) (центральная чёрная дыра не входит в группы), затем следующее и т.д.
- Делим галактику на 6 угловых сегментов и 8 радиальных колец; в центрах полученных фрагментов строим группы (примарно кучкой).
- Центр фрагмента выбираем как случайную звезду внутри фрагмента.
- Основная функция генерации созвездий — оркестратор. Он вызывает функции стадий расчёта; дробление на стадии должно быть удобным для будущих изменений и читаемым.
- Первый проход по всем звёздам: если у звезды нет соседки ближе лимита, она исключается из расчётов.
- Радиальные кольца делим по равной площади: границы считаем по `r^2`, затем берём `sqrt` для порогов.
- `Rmax` берём по фактическому максимуму радиуса `oldX/oldY` среди всех звёзд (центральную не считаем).


## Общий поток
1. `GalaxyCreator.Create()` строит массив `StarSys` длиной `StarCount` (сейчас 1300).
2. Сначала создаётся «каркас» спиральной галактики (`CreateSpiralGalaxy`):
   - центр (индекс 0) фиксируется в (0,0,z);
   - остальные системы размещаются с минимальной дистанцией.
3. Для каждой системы:
  - задаётся `DisplayName` (строка имени системы/звезды);
   - для центра (index 0) звезда уже задана, только копируются метаданные;
   - для остальных создаётся звезда, планеты, луны и система планет.

## Размещение звёзд (GalaxyCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/GalaxyCreator.cs`

### Параметры
- `StarCount = 1300`
- `GalaxyRadius = 500`
- `GalaxyStarLayer = 0`
- `DensityArms = 3`
- `WidthArms = 60`
- `MinStarInterval = 3.5`
- `CentralBlackHoleIntervalK = 10`
- `MaxAttemptsPerStar = 64`

### Как ставятся координаты
- Координаты (x,y) формируются в `GenerateStarsNoGaussianDistr`:
  - берём случайное `xSeed` в [-1;1], избегаем 0;
  - `y` в диапазоне [-GalaxyRadius; GalaxyRadius];
  - `x` скручивается через `DensityArms` и `WidthArms`;
  - применяется `TwistCoordinates`, чтобы получить спираль.
- В `PlaceWithMinDistance`:
  - берём кандидата, проверяем расстояние до уже поставленных;
  - для центра используется повышенный минимальный радиус (`* CentralBlackHoleIntervalK`);
  - максимум 64 попытки, если не получилось — берётся последний кандидат.

## Генерация звезды (StarCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/StarCreator.cs`

### Что выбирается
- Тип звезды по весам (`TypeWeights`):
  - Red 20, Orange 20, Yellow 10, White 7, Blue 3, Neutron 2, Black 1
- Размер звезды по типу (`*SizeWeights`).
- Температура, масса, радиус, светимость, возраст, металличность, стабильность — случайно в заданных диапазонах.
- UID создаётся через `UIDService.Create(EntityType.Star)`.

## Орбиты планет (PlanetOrbitCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/PlanetOrbitCreator.cs`

### Логика
- Внутренняя граница зависит от размера звезды (`InnerCutoff`).
- Внешняя граница зависит от типа звезды (`OuterLimit`).
- Минимальный разрыв между орбитами зависит от размера (`MinGap`).
- Число планет берётся из диапазона по типу звезды + модификатор по размеру.
- Орбиты выбираются жадно: список кандидатов перемешивается и отбирается с учётом разрыва.
- Итог: массив занятых орбит (1-based).

## Планеты (PlanetCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/PlanetCreator.cs`

### Логика
- Зоны: горячая, обитаемая, тёплая внешняя, холодная внешняя.
- Порог «снежной линии» зависит от типа звезды.
- Тип планеты выбирается по весам для зоны.
- Радиус планеты берётся из диапазона по типу и масштабируется по типу звезды.
- Создаётся `Planet` с:
  - `Uid`
  - `Name` пустая строка
  - `Type`
  - `Radius`

## Орбиты лун (MoonOrbitCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/MoonOrbitCreator.cs`

### Логика
- Класс размера планеты определяется по радиусу (Small/Medium/Large).
- Внутренняя граница лун — зависит от типа и размера.
- Внешняя граница лун — зависит от типа и размера (как суррогат сферы Хилла).
- Число лун выбирается по профилю весов (Low/Mid/High).
- Орбиты выбираются рулеткой по весам удалённости и с минимальным разрывом.

## Луна (MoonCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/MoonCreator.cs`

### Логика
- Тип луны выбирается из весов по типу планеты.
- Веса корректируются:
  - по типу звезды (жёсткие звёзды повышают Blasted/Toxic);
  - по орбите луны (ближе — больше Lava/Stone, дальше — Ice/Ocean).
- Размер луны выбирается по весам от класса размера планеты.
- Создаётся `Moon` с:
  - `Uid`
  - `Name` пустая строка
  - `Type`
  - `Size`
  - `OrbitIndex`

## Система планеты (PlanetSysCreator)
Файл: `Assets/_Project/Classes/Galaxy/Generation/PlanetSysCreator.cs`

### Логика
- Индекс орбиты планеты переводится в сценовые юниты (`OrbitUnitPlanet = 10`).
- Радиус планеты переводится в юниты (`PlanetRadiusToUnits = 0.6`).
- Внешний «габарит» системы = визуальный радиус планеты + дальняя лунная орбита.
- Угол орбиты выбирается детерминированно:
  - базовый угол по хэшу UID звезды и индекса орбиты;
  - при конфликте с соседями добавляется золотой угол, до 64 попыток;
  - хранится в `PlacedByStar` для контроля пересечений.
- `PlanetSys` получает:
  - `MotherStar`
  - `OrbitIndex`
  - `Planet`
  - `OrbitPosition` (радианы)
  - `Moons`

## Имена
   - `StarNameCatalog.PrepareStarNames` вызывается перед генерацией систем.
- Имена звёзд/планет/лун создаются на лету и регистрируются в локализации.

## Что важно знать
- Все индексы орбит планет и лун — 1-based.
- Визуальные масштабы орбит (10/1.6/0.6) захардкожены в генераторах.
- Генерация сейчас не детерминирована по сидy (Unity Random).
- `PlanetOrbits` всегда имеет длину 20: это фиксированный массив орбит. Пустые ячейки означают отсутствие планеты на данной орбите; но сами орбиты существуют всегда и могут использоваться для спауна/расчётов (в т.ч. для зон Continuum).
